# DotNet Core + Angular Dating App

A full-stack web application for connecting people, built with **ASP.NET Core** for the backend and **Angular** for the frontend.

## 📋 Overview

This project is a modern dating application that combines the power of .NET Core and Angular to create a responsive, feature-rich user experience. It demonstrates best practices in building scalable web applications with separation of concerns between frontend and backend.

## 🛠️ Technology Stack

- **Backend**: ASP.NET Core (.NET)
- **Frontend**: Angular with TypeScript
- **Styling**: CSS
- **Architecture**: REST API with single-page application (SPA)

### Language Breakdown
- **C#**: 104,820 bytes (~62%) - Backend logic and API
- **TypeScript**: 63,074 bytes (~37%) - Frontend components and services
- **HTML**: 40,047 bytes (~2%) - Angular templates
- **CSS**: 121 bytes - Styling

## 🚀 Getting Started

### Prerequisites
- [.NET Core SDK](https://dotnet.microsoft.com/download)
- [Node.js](https://nodejs.org/) and npm
- [Angular CLI](https://angular.io/guide/setup-locally)

### Backend Setup
```bash
cd backend
dotnet restore
dotnet build
dotnet run
```

The API will be available at `http://localhost:5000`

### Frontend Setup
```bash
cd frontend
npm install
ng serve
```

The application will be available at `http://localhost:4200`
